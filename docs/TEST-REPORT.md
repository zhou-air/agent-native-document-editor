其他可靠性检查：

- 合并表格按独立人工定义的逻辑矩阵比较，包含 gridSpan + vMerge、合并单元格多段落。不是通过截图相似度判断。
- 图片同名不同内容独立保存、相同图片重复引用、表格内图片均验证。
- 两个并发 MCP 写入同一版本，恰有一个成功；另一个返回 409，无部分覆盖。
- UI 有未提交输入时 MCP 修改别的块，双方内容都保留；同一块冲突时保存服务端赢家并保留 UI 草稿。
- 第二个 Store 无法取得同一项目的写锁。
- 不支持的 Word 域产生警告，原始 DOCX 字节保留。
- MCP 单独启动：未启动 GUI/服务，调用 open_project 自动拉起服务并完成读写。
- 打包后的 Electron Node 模式可直接充当 MCP 命令，无额外 Node 安装。

## 测试过程中修复

- 给表格拆分后克隆出的单元格重新分配 UUID，原有内容节点身份保留，事务可撤销。
- 样式面板默认只编辑常用语义规则和页面，原始定义与局部覆盖分开展示，避免大段 XML 信息影响编辑。
- 自动保存时保留“移动到章节”的目标选择。
- 修复默认正文样式继承与显式大纲级别 9 的处理。
- 规范测试中的焦点和历史分组：Tiptap 异步 focus 需等待，连续小于 500 ms 的输入会合并为一个撤销步骤；没有把测试驱动差异当成产品修复。
- 修正打包 MCP 配置的路径为 resources/app.asar/src/mcp.js，并实际测试。

最终回归无未解决失败。早期失败已修复或定位为测试驱动问题，最终报告只引用最后成功运行的结果。
